# 负 Gamma 踩踏完整观测框架

（政治尾部风险诱发的做市商自我强化螺旋）

---

## 一、核心机制

当不可量化的宏观尾部风险（如中期选举）击穿基于历史波动率与连续交易假设的微观对冲机制后，做市商前期累积的**负 Delta + 负 Gamma**仓位会陷入自我强化螺旋：价格下跌 → 对冲卖压加大 → 流动性被吸干 → 进一步下跌。原本提供流动性的动态对冲，瞬间异化为吸干流动性的加速器，最终导致断崖式缺口。

---

## 二、踩踏启动观测框架

### 1. 一阶核心：Dealer 仓位结构（火药）
- Dealer GEX（净 Gamma 暴露）
- Dealer DEX（净 Delta 暴露）
- Zero Gamma / Gamma Flip 水平
- Call Wall / Put Wall

### 2. 二阶领先与结构信号（暗流与压力升温）

| 指标 | 核心含义 | 危险信号 |
|------|----------|----------|
| VVIX | 对冲工具本身的紧张/稀缺程度 | VIX 低位时，VVIX 升破 110–120 |
| VIX / SPX | 单位指数点位对应的波动率定价强度 | 比值在 SPX 高位时持续抬升 |
| 波动率期限结构 | 市场在为「当下冲击」还是「遥远未来」定价 | 近端（如9天期）隐含波动率超过30天VIX，形成倒挂 |
| Skew（偏斜） | 机构购买灾难保险的迫切程度 | 深度虚值Put相对平值的隐含波动率溢价急剧走阔，出现极端负偏斜 |

### 3. 事中微观确认（流动性被吸干的直接证据）

| 指标 | 核心含义 | 危险信号 |
|------|----------|----------|
| 订单簿深度与价差 | 做市商是否还在提供双边流动性 | 买盘深度迅速变薄，买卖价差异常扩大 |
| 价格影响比率 | 订单簿吸收能力是否丧失 | 同样规模卖单打穿的价格档位远多于平时 |
| 跳空与无成交区间 | 价格发现是否已断裂 | 价格直接跳过若干价位，缺口上沿未被快速回补 |

### 启动证据链（实操顺序）

1. **结构定位**：现价位于 Gamma Flip 下方，或正在有效跌破。
2. **内部紧张**：VVIX 升破关键区间 + 期限结构出现近端倒挂（辅助看 VIX/SPX 与 Skew）。
3. **微观验证**：价格下跌时，买盘深度骤降、价差走阔、价格影响放大、出现跳空。

**三者共振**，才构成「负 Gamma 踩踏正在发生」的完整证据链。

---

## 三、踩踏结束 / 情况反转观测框架

### 结束证据链（实操顺序）

1. **结构前提**：GEX 翻正，且价格站稳在翻正后的 Gamma Flip 上方。
2. **压力前提**：
   - 负 Gamma 集中区因到期或仓位耗尽而明显消失/减弱
   - 波动率内部紧张信号缓解：VVIX 回落、期限结构倒挂修复、Skew 极端程度收敛
3. **行为确认**：价差与盘口深度同步修复：买盘重新变得厚实，买卖价差回归正常，价格影响比率下降，跳空缺口被有效回补或不再出现新的无成交区间。

**三者递进共振**，才构成「踩踏机制已解除」的完整证据链。

---

## 四、核心使用原则

- **启动阶段**：防「假跌破后的加速踩踏」。
- **结束阶段**：防「结构刚翻正但盘口尚未修复」的假反弹。
- 始终坚持「结构 → 压力 → 行为」的递进验证，拒绝单一指标的过度解读。
- 多信号共振时，政治尾部风险落地后演变成流动性踩踏（或踩踏结束）的概率显著上升。

---

**框架定位一句话**  
GEX/DEX 与 Gamma Flip 看做市商是否站在悬崖边；VVIX、VIX/SPX、期限结构与 Skew 看对冲需求与内部压力是否在升温；订单簿深度、价差、价格影响与跳空，则是流动性被真正吸干（或重新恢复）的最直接盘口证据。
