# US Equity Liquidity Monitor

**负 Gamma 踩踏完整观测框架**  
Daily observation system for US equity (primarily SPX) liquidity risks driven by Dealer Negative Gamma + Negative Delta spirals.

> 政治尾部风险 / 宏观冲击 → 击穿微观对冲假设 → 做市商负 Gamma 自我强化螺旋 → 流动性被吸干 → 断崖式缺口

---

## 核心机制（一句话）

当不可量化的宏观尾部风险击穿基于历史波动率与连续交易假设的微观对冲机制后，做市商前期累积的 **负 Delta + 负 Gamma** 仓位陷入自我强化螺旋：价格下跌 → 对冲卖压加大 → 流动性被吸干 → 进一步下跌。原本提供流动性的动态对冲，瞬间异化为吸干流动性的加速器。

---

## 框架结构

### 1. 踩踏启动观测

#### 一阶核心：Dealer 仓位结构（火药）
- Dealer GEX（净 Gamma 暴露）
- Dealer DEX（净 Delta 暴露）
- Zero Gamma / Gamma Flip 水平
- Call Wall / Put Wall

#### 二阶领先与结构信号
| 指标 | 核心含义 | 危险信号 |
|------|----------|----------|
| **VVIX** | 对冲工具本身的紧张/稀缺程度 | VIX 低位时，VVIX 升破 110–120 |
| **VIX / SPX** | 单位指数点位对应的波动率定价强度 | 比值在 SPX 高位时持续抬升 |
| **波动率期限结构** | 市场在为「当下冲击」还是「遥远未来」定价 | 近端（如9天期）隐含波动率超过30天VIX，形成倒挂 |
| **Skew（偏斜）** | 机构购买灾难保险的迫切程度 | 深度虚值Put相对平值的隐含波动率溢价急剧走阔 |

#### 事中微观确认
| 指标 | 核心含义 | 危险信号 |
|------|----------|----------|
| 订单簿深度与价差 | 做市商是否还在提供双边流动性 | 买盘深度迅速变薄，买卖价差异常扩大 |
| 价格影响比率 | 订单簿吸收能力是否丧失 | 同样规模卖单打穿的价格档位远多于平时 |
| 跳空与无成交区间 | 价格发现是否已断裂 | 价格直接跳过若干价位，缺口上沿未被快速回补 |

#### 启动证据链（必须三者共振）
1. **结构定位**：现价位于 Gamma Flip 下方，或正在有效跌破
2. **内部紧张**：VVIX 升破关键区间 + 期限结构近端倒挂
3. **微观验证**：买盘深度骤降 + 价差走阔 + 价格影响放大 + 跳空

---

### 2. 踩踏结束 / 反转观测

#### 结束证据链（必须三者递进共振）
1. **结构前提**：GEX 翻正，且价格站稳在翻正后的 Gamma Flip 上方
2. **压力前提**：负 Gamma 集中区因到期/耗尽而消失 + VVIX回落 + 期限结构修复 + Skew收敛
3. **行为确认**：价差与盘口深度同步修复，价格影响比率下降，跳空被回补

---

## 每日观测流程（推荐）

1. **盘前 / 开盘后**：更新 GEX、DEX、Gamma Flip、Call/Put Wall
2. **重点监控二阶信号**：VVIX、VIX/SPX、期限结构、Skew
3. **价格异动时**：立即切换到订单簿深度、价差、价格影响、跳空观察
4. **收盘后**：记录当日证据链状态，判断处于「安全 / 警戒 / 踩踏中 / 修复中」哪一阶段
